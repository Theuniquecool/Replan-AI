
# REPLAN AI 🚀
### Your Week. Rebuilt.

An open-source student productivity application designed to help students manage tasks, deadlines, commitments, and unexpected schedule changes.

🌐 **Live Demo:** https://replaneai.netlify.app/#dashboard

## About the Project

REPLAN AI was initially developed during **Prompt Wars: AI Arena at RUVERSE TechFest 2026** using AI-assisted development and prompt engineering.

The goal is simple: help students create realistic weekly plans and recover when unexpected events disrupt their schedules.

## Features

- 📊 Productivity dashboard
- 📅 Weekly schedule and calendar
- ✅ Task and deadline management
- 🔒 Fixed commitments
- ⚡ Chaos Button for unexpected disruptions
- 🔄 Schedule recovery with preview and apply
- 💾 Browser-based local storage
- 🌙 Dark-themed responsive interface

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser localStorage
- AI-assisted development

The current prototype uses rule-based scheduling logic. It does not require an external AI API.

## Getting Started

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add tasks and commitments.
4. Use the Chaos Button to explore schedule recovery.

No backend or API key is required for the current version.

## Privacy

The current application stores task data in the user's browser using localStorage.

Data is not automatically synchronized between devices. Clearing browser storage may remove saved information.
